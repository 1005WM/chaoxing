- [x] 用 Xcode 工具链，在独立 iPhone 17 Pro 模拟器完成编译、链接、资源打包和冷启动（2026-11-17）。

- [ ] VoiceOver 按合理顺序读出账号、密码、按钮和错误信息。

## 登录后的只读和本地验证

由维护者在自己的授权测试账号中操作，不在问题报告中记录凭据或真实二维码。

- [ ] 登录、拉取课程、常用课程筛选、群列表及活动详情正常；请求失败显示错误而非伪装成“无活动”。
- [ ] 切换账号时旧导航、课程、群聊和待签活动清空，不被旧请求覆盖。
- [ ] 设置、管理地点、学校选择、账号分组与历史页面可正常操作；无障碍选中状态可读。
- [ ] 备份默认不含账号；导出→修改本地设置→导入能恢复承诺的字段，并保留现有条目。完整备份只保存在受控位置。
- [ ] App 强制退出后重启，本地状态恢复正常；损坏文件恢复仅在独立、可丢弃的测试数据上验证。

## 设备权限和交互

- [ ] 真机按 README 配置个人 Team/Bundle Identifier；不关闭签名检查。
- [ ] 相机首次允许、拒绝、系统设置后返回、重复打开关闭与后台切换均无崩溃或持续占用。

## 有副作用的业务验收

仅在明确允许的测试活动中进行；模拟器与单元测试不能证明真实考勤有效。

- [ ] 普通、位置、照片、二维码、手势、签到码、签退及所需校验分别验证允许的成功/失败路径。
- [ ] 全部取消账号勾选时不能提交；每个目标账号的身份、头像和结果独立。
- [ ] 已签到或已结束活动不会重复提交；错误二维码不能替换当前目标。
- [ ] 批量等待期间取消、退出页面、切换账号或注销，停止后续请求。已经发出的请求不能撤回。
- [ ] 会话及 IM Token 过期可以恢复一次；再次失败给出错误，不无限重试或重复上传照片。
